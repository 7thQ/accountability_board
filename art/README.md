# Art box

Drop files in this folder and they show up in the shuffle on the right side of the board.

- `.gif`, `.png`, `.jpg`, `.jpeg`, `.webp` — shown as images (gifs animate on their own).
- `.txt` — ascii art. A single frame is shown static; split multiple frames with a line
  containing `---FRAME---` and they'll be cycled to animate, e.g. `dancer.txt`.

Anything else in this folder is ignored.
